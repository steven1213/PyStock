# 创业板股票分析与回测项目

## 项目目标
本项目旨在从创业板获取股票数据，分析涨幅超过10%的股票，并进行回测，以找出有效的选股策略。

## 项目结构

~~~
project/
│
├── main.py # 主程序，负责调用数据获取和分析功能
├── config.py # 配置文件，存储常量和配置信息
├── data_fetcher.py # 数据获取模块，负责从Tushare获取股票数据
├── analyzer.py # 分析模块，分析涨幅超过10%的股票
├── backtester.py # 回测模块，验证选股策略的有效性
└── data/ # 存储日线数据的目录
├── 20230101.csv # 示例数据文件
└── 20230102.csv # 示例数据文件
~~~

## 使用说明

### 环境准备
1. 安装所需库：
   ```bash
   pip install tushare pandas
   ```

2. 设置Tushare的token：
   - 在 `data_fetcher.py` 中替换 `your_token_here` 为您的Tushare token。

### 数据获取
- 使用 `data_fetcher.py` 中的 `fetch_stock_list` 函数获取创业板股票列表。
- 股票列表会被缓存到 `stock_list.csv` 文件中，只有在文件过期时才会重新获取。

### 数据分析
- 使用 `analyzer.py` 中的功能分析涨幅超过10%的股票，并找出其共性特征（如行业分布、平均成交量等）。

### 回测策略
- 使用 `backtester.py` 中的功能对选股策略进行回测，验证其有效性。

## 数据格式
每个日线数据文件包含以下字段：
- `trade_date`：交易日期
- `open`：开盘价
- `high`：最高价
- `low`：最低价
- `close`：收盘价
- `pre_close`：昨收价（除权价，前复权）
- `change`：涨跌额
- `pct_chg`：涨跌幅（基于除权后的昨收计算的涨跌幅）
- `vol`：成交量（手）
- `amount`：成交额（千元）

## 注意事项

- 根据需要调整日期范围和分析逻辑。
